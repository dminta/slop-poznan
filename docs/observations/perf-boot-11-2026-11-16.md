# Faster boot, part 11: headless lane-rail segment filter, curb-frame cache, curve tables and tram-surface flat grid (2026-11-16)

## Result

Against baseline `aed38d9` (main checkout vs `agy-boot11` worktree, Node v26.13.1, five interleaved headless world builds), median total build time falls **10,423.7 → 10,035.3 ms (−388.4 ms, −3.73%)** and minimum build time falls **10,365.6 → 9,981.9 ms (−383.7 ms, −3.70%)**. Every interleaved pair (5/5) is faster on the worktree (**−340.7 to −415.0 ms**); run-to-run spread is **98.4 ms (0.9%)** main / **141.4 ms (1.4%)** worktree. `signalHeads` drops **2,309.6 → 2,010.8 ms median (−298.8 ms, −12.9%)**; `tramInfra` drops **268.9 → 187.4 ms median (−81.5 ms, −30.3%)**; `cityGrid` drops **1,138.0 → 1,086.3 ms median (−51.6 ms, −4.5%)**; `blocks` drops **1,484.1 → 1,476.7 ms median (−7.4 ms, −0.5%)**. Retained `heapUsed` after forced GC increases by **+0.06 MiB** (**614.50 → 614.56 MiB**), `arrayBuffers` increases by **+0.32 MiB** (**47.74 → 48.06 MiB**), and `external` increases from **54.35 → 96.26 MiB** (**+41.91 MiB** non-ArrayBuffer V8/Node external accounting, while `rss` is lower at 1.55 GB vs 1.62 GB). All **24** reconstructed build-output SHA-256 hashes match identically, and no test pins or source-slice markers were changed. Browser boot (1× / 6×) was not run in this pass.

## Method

- Read `AGENTS.md`, `docs/testing.md`, `docs/backlog.md`, and `docs/observations/perf-boot-10-2026-11-15.md` and `perf-boot-9-2026-11-14.md` first; no rejected candidates from those records were retried.
- `tools/bench-boot-headless.mjs` runs the headless world build (`config` → `blocks` → `cityGrid` → `streetDetails` → `traffic` → `tramLayout` → `railLayout` → `signalHeads` → `paint` → `tramInfra` → `trams`) using `tests/helpers/module.cjs` (`loadModule`) with inert Three.js/TSL stand-ins, seeded `Math.random` (4242), real `city-config.js` / `geodata.js` and `SPECIES_CROWN_R`.
- `node --cpu-prof` (3 runs each, `timeDeltas`-weighted median self / inclusive ms parsed by an uncommitted scratch script in `/tmp/boot11/parse-prof.mjs`) ranked application functions before and after edits.
- An uncommitted scratch script (`/tmp/boot11/count-callers.mjs`) instrumented an in-memory copy to count calls across phases (`railWithin`, `laneClear`, `nearestCurbFrame`, `walkable`). No instrumentation exists in shipped `js/`.
- Five interleaved pairs (`main` then `worktree`, `node --expose-gc tools/bench-boot-headless.mjs --gc`) measured median, min, spread, retained `heapUsed`, `external` and `arrayBuffers`.

## Changes retained

1. **Exact segment-to-segment `railSegHasSegs` pre-filter for `laneClear` (`js/city-grid.js`, `js/pedestrian-routes.js`).**
   - Adds `railClearance.segHasRails = railSegHasSegs(ax, az, bx, bz, d)` using exact 2D segment-to-segment squared distance against `railCells()` with `1e-3` m slack (covering near-parallel closest-pair rounding on long segments), replacing `boxHasRails` in `laneClear` when available and cutting `railWithin` self time **572.8 → 289.6 ms** (−49.4%).
2. **Per-edge frame cache, precomputed `valid` mask and inlined test in `nearestCurbFrame` (`js/street-details.js`).**
   - Precomputes `valid` (`len >= 1e-6`) in `curbEdgeIndex`, inlines the per-edge distance check in `nearestCurbFrame` without allocating a `test` closure per call, and caches `{ acrossX, narrow, pitRot, squeeze, tier, grate, pitS }` per `(block, bestI)` edge (eliminating redundant `blockAt` calls on 82.1% of queries).
3. **Skip duplicate `clearOfRails` in `findOverhead` (`js/street-details.js`).**
   - Passes `skipRail = true` from `findOverhead` to `failures(px, pz, true, true)` when `mastClear(px, pz)` has already verified `clearOfRails(px, pz, 1.1)` (strictly stronger than `0.22`).
4. **Precomputed Bernstein basis tables and hoisted first-derivative differences in `makeCurve` (`js/road-network.js`).**
   - Precomputes the 17-point cubic Bézier basis and derivative tables (`CURVE_B0..B3`, `CURVE_D0..D2`, `CURVE_DD0..DD1`) and hoists first-derivative control-point differences (`dx0..dx2`, `dz0..dz2`), while preserving the original second-derivative expressions (`x2 - 2 * x1 + x0`, `x3 - 2 * x2 + x1`) and `Math.hypot(dx, dz) ** 3` so `c.curv` stays bit-identical.
5. **Flat `Int32Array` bucket index for `TRAM_SURFACE_GRID` (`js/city-config.js`).**
   - Replaces `Map` hash lookups in `inTramSurfaceCut` and `tramSurfaceClearance` with `TSC_FLAT` + `TSC_BUCKETS` (`inTramSurfaceCut` **71.7 ms** → below top 35). Unlike the rejected flat `Int32Array` grid for `railWithin` (which spanned the entire city including sparse mainline tracks), `TSC_FLAT` covers only the compact urban `tram` surface cut bounding box (32 m cells, ~0.3 MiB).

## Rejected attempts (ablated and reverted)

1. **Flat `Int32Array` grid (`landingFlat`) for `landingGrid` in `clearOfCrosswalks` (`js/street-details.js`).**
   - In `node --cpu-prof`, `clearOfCrosswalks` rose **136.5 → 167.2 ms**, and 3 interleaved `--gc` pairs (`no` vs `yes`) showed **+82.5, −67.9, +17.5 ms** total (**−4.6, −16.9, +4.7 ms** `streetDetails`) — no reliable gain over the `Map`, so reverted.
