# Kit roof audit, 2026-11-13

No shipping-code changes were needed. All 75 kit roofs (54 x-ridge, 21 z-ridge) have outward winding and matching
stored normals after their actual world transforms. Midday browser views found no missing roof slopes or unexplained
face-darkening on the inspected landmarks on WebGPU or WebGL2.

## Geometry audit

Scratch driver: `.agent-task/audit.mjs`, using `tests/helpers/module.cjs` to load the real kit and all eight landmark
area builders before facade conversion/batching removes mesh identity. Geometry/math come from the exact pinned
Three.js commit's `three.core.js`; node materials and TSL are stubbed, and DOM-only mural painting is skipped.
The repository Three stub's `computeVertexNormals` is a no-op, so it cannot validate the stored-normal requirement.
Only scratch source instrumentation attaches roof dimensions/options and the fit site's landmark name.

`audit.json` lists every roof's size, ridge, hip, mesh rotation (`optsRy`), complete parent rotations/scales,
world centre, footprint edge lengths and world ridge direction. Footprint lengths use transformed local edges,
not the world AABB, so turned blocks are measured in their own frame. Every nonzero triangle is checked against
an interior point at half roof height, with positive world y for slopes; stored normals use the inverse-transpose
normal matrix, compared to the transformed geometric normal at all three vertices (3° tolerance).

436 nonzero triangles pass; maximum stored/geometric angle is 0.00000342°. Fourteen zero-area triangles are the
expected collapsed ridge pieces on square pyramids: four real side triangles remain, without holes or shared smooth
normals. They are counted separately, not treated as inward triangles. No actual roof has a negative determinant.
A second run with the entire landmark root rotated 0.73 rad and scaled (−1.2, 0.8, 1.5) also passes all 75 roofs
(`audit-mirrored.json`). It accounts for Three.js's front-face reversal on negative world determinants; raw cross
products reverse under reflection, whereas outward stored normals use the inverse transpose.

No visible ridge light leaks, ridge/eave z-fighting or roof shader errors. These are sampled static views with a
short settling interval, not an exhaustive temporal flicker test or a physical-device survey. Low inset roofs
behind parapets cannot be judged from ground level; their slopes were judged in the aerial views.
No page exceptions, console errors or warnings were recorded in either backend run or the street refinement run.

The first batch reused one Chrome for both backends and all 27 captures. Its automatic cleanup ran before the
obstructed street frames were reviewed; a second reused Chrome session was needed to refine those frames. This
is a deviation from the requested single-launch limit. No Chrome was launched per landmark. The refinement
attached to the second session rather than launching more browsers. Both sessions and the port-8014 server
were stopped after capture. No other server port or existing browser session was touched.
