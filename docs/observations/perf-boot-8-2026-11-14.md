# Faster boot, part 8: headless caller threshold-only, outline-tree, route-grid and footprint-filter pass (2026-11-14)

## Result

Against baseline `7a4268e` (main checkout vs `agy-boot8` worktree, Node v26.13.1, five interleaved headless world builds), median total build time falls **13,683.6 → 12,239.5 ms (−1,444.1 ms, −10.55%)** and minimum build time falls **13,599.7 → 11,850.9 ms (−1,748.8 ms, −12.86%)**, exceeding the **702.8 ms (5.1%)** main / **1,035.3 ms (8.5%)** worktree run-to-run spread. `signalHeads` (runtime signal heads and lazy pedestrian routes) drops **3,139.6 → 2,574.0 ms median (−565.6 ms, −18.0%)**; `blocks` drops **2,361.8 → 1,857.5 ms median (−504.3 ms, −21.4%)**; `railLayout` drops **1,053.2 → 823.3 ms median (−229.9 ms, −21.8%)**; `streetDetails` drops **4,444.7 → 4,378.4 ms median (−66.3 ms, −1.5%)**. Retained `heapUsed` after forced GC increases by **+2.40 MiB** (**582.76 → 585.17 MiB**, from the lazy 64 m `segmentsNear` grid), all **24** reconstructed build-output SHA-256 hashes match identically, and no test pins were changed. Browser boot (1× / 6×) was not run in this pass (left to the coordinator).

## Method

- Read `AGENTS.md`, `docs/testing.md`, `docs/backlog.md`, `docs/observations/perf-boot-7-2026-11-14.md`, `perf-boot-6-2026-11-14.md`, `perf-boot-5-2026-11-12.md` and `perf-boot-4-2026-11-12.md` first; no rejected candidates from those records were retried.
- `tools/bench-boot-headless.mjs` runs the headless world build (`config` → `blocks` → `cityGrid` → `streetDetails` → `traffic` → `tramLayout` → `railLayout` → `signalHeads` → `paint` → `tramInfra` → `trams`) using `tests/helpers/module.cjs` (`loadModule`) with inert Three.js/TSL stand-ins, seeded `Math.random` (4242), real `city-config.js` / `geodata.js` and `SPECIES_CROWN_R`.
- `node --cpu-prof` (3 runs each, median self / inclusive ms parsed by an uncommitted scratch script) ranked application functions before and after edits.
- An uncommitted scratch script instrumented a scratch in-memory copy (sampling `nearestDist`/`nearest`/`outlineDist` 1/10, `railWithin`/`nearSegment` 1/20, `footprintIndex` 1/50, `pointInPolyIndexed` 1/100; exact total & duplicate-point counts for `outlineDist` and `nearestDist`). No instrumentation exists in shipped `js/`.
- Five interleaved pairs (`main` then `worktree`, `node --expose-gc tools/bench-boot-headless.mjs --gc`) measured median, min and spread.

## Changes retained

1. **Threshold-only callers in `tram-infra.js` + single-cell `within` fast path.**
   - `segmentGrid.within` skips `sg._q` deduplication when `ix0 === ix1 && iz0 === iz1` (single-cell queries).
   - `laneDistance` attaches `.within` to the anonymous `laneDist` closure (preserving `fn.name === ''` for hash parity).
   - `clearSpot`, `shelterClear` and `platformClear` use `laneDist.within` and `trackWithin` with exact thresholds (`2.0`, `LANE_HALF - 1e-6`, `LANE_KEEP`, `TRACK_KEEP`, `PLATFORM_EDGE`) instead of `nearestDist` at `r = 6` / `4`.
   - `layoutRailInfrastructure` adds `roadWithin(x, z, thresh)` (returning `true` immediately when `roadClearance(x, z) < thresh`, otherwise calling `laneDist.within(x, z, thresh + 1.75)`), `tramWithin`, `railWithin` and `fenceGrid.within(x, z, 0.4)` across all threshold-only checks.
2. **Precomputed flat edge arrays and branchless node AABB in `outlineDist` (`js/buildings.js`).**
   - `outlineDistanceTree` precomputes `Float64Array`s `eAx`, `eAz`, `eDx`, `eDz`, `eL2` once per block and stores leaf `ids` as `Int32Array`.
   - `outlineDist` uses branchless `bx`/`bz` clamping instead of variadic `Math.max` and loops over typed arrays without touching `poly` objects.
3. **64 m spatial grid in `segmentsNear` and centre-rail reuse in `laneClear` (`js/pedestrian-routes.js`).**
   - `getSegNearGrid()` builds a lazy 64 m cell index over `edges` and `crosswalks`, keeping `nearSegment` intact and sorting matched indices to preserve exact iteration order.
   - `laneClear` caches `railWithin(cx, cz, RAIL_KEEP)` in a reusable `Uint8Array` (`laneCenterRail`) across the two `side` passes (`-1` and `1`).
4. **Skip `flags === 0` rectangles when building `createFootprintIndex` (`js/road-network.js`).** Skips filing rectangles whose computed `flagOf(r)` is `0` into `cells`/`buckets`.

## Rejected attempts

1. **Precomputing `ex, ez, L2` fields on every `segmentGrid` segment (`js/tram-infra.js`).** Adding three properties to every segment object in `laneGrid`, `trackGrid`, `railGrid`, `tramGrid`, `deckGrid` and `fenceGrid` increased retained `heapUsed` after forced GC by **+30.07 MiB** (**582.76 → 612.83 MiB**) while only trimming `within` slightly (~429 → ~411 ms). Reverted; retained `heapUsed` returned to **585.17 MiB (+2.40 MiB)**.
