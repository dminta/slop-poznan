# Faster boot, part 10: headless road-clearance, polygon-vertex, footprint-cell and tram-nearest pass (2026-11-15)

## Result

Against baseline `e3ba722` (main checkout vs `agy-boot10` worktree, Node v26.13.1, five interleaved headless world builds), median total build time falls **10,083.6 → 9,953.9 ms (−129.8 ms, −1.29%)** and minimum build time falls **10,039.3 → 9,801.5 ms (−237.8 ms, −2.37%)**. Every interleaved pair (5/5) is faster on the worktree (**−105.6 to −351.8 ms**); run-to-run spread is **318.6 ms (3.2%)** main / **204.5 ms (2.1%)** worktree. `streetDetails` drops **3,484.5 → 3,369.8 ms median (−114.7 ms, −3.3%)**; `blocks` drops **1,549.7 → 1,480.3 ms median (−69.4 ms, −4.5%)**; `railLayout` drops **761.0 → 698.7 ms median (−62.3 ms, −8.2%)**; `signalHeads` drops **1,977.9 → 1,946.6 ms median (−31.3 ms, −1.6%)**. Retained `heapUsed` after forced GC increases by **+3.80 MiB** (**585.82 → 589.62 MiB**, from precomputed `LANE_GUIDE` segment objects in `GUIDE_GRID` and packed `px`/`pz` `Float64Array` vertex coordinates in `createPolygonIndex`), all **24** reconstructed build-output SHA-256 hashes match identically, and no test pins or source-slice markers were changed. Browser boot (1× / 6×) was not run in this pass.

## Method

- Read `AGENTS.md`, `docs/testing.md`, `docs/backlog.md`, and `docs/observations/perf-boot-9-2026-11-14.md` through `perf-boot-6-2026-11-14.md` first; no rejected candidates from those records were retried.
- `tools/bench-boot-headless.mjs` runs the headless world build (`config` → `blocks` → `cityGrid` → `streetDetails` → `traffic` → `tramLayout` → `railLayout` → `signalHeads` → `paint` → `tramInfra` → `trams`) using `tests/helpers/module.cjs` (`loadModule`) with inert Three.js/TSL stand-ins, seeded `Math.random` (4242), real `city-config.js` / `geodata.js` and `SPECIES_CROWN_R`.
- `node --cpu-prof` (3 runs each, `timeDeltas`-weighted median self / inclusive ms parsed by an uncommitted scratch script in `/tmp/boot10/parse-prof.mjs`) ranked application functions before and after edits.
- Uncommitted scratch scripts (`/tmp/boot10/count-callers.mjs`, `/tmp/boot10/diag-hotspots.mjs`) instrumented an in-memory copy to count calls, consecutive duplicates, empty-cell hits and loop iterations. No instrumentation exists in shipped `js/`.
- Five interleaved pairs (`main` then `worktree`, `node --expose-gc tools/bench-boot-headless.mjs --gc`) measured median, min, spread and retained `heapUsed`.

## Caller counts and profile findings

Baseline scratch caller counts (with `--hashes` materialising all lazy pedestrian links):

- `roadClearance` (`city-config.js`): **3,307,411** calls (`13,879` consecutive duplicates; `1,173,213` empty-cell hits; `16,085,349` segment visits across non-empty cells, ~7.54 per non-empty call). Recomputed `dx, dz, L2`, destructured `[ax, az, bx, bz, half]`, allocated `|| []` on empty cells, and called `Math.hypot` unconditionally without bbox or squared-distance rejection.
- `pointInPolyIndexed` (`city-config.js`): **12,415,214** calls (`95,983` consecutive duplicates; `1,365,933` rejected by `z0`/`z1`, `114,645` by `x0`/`x1`; `10,934,636` entered the edge loop, checking `40,505,246` edges). Read `poly[i]` and `poly[j]` JS objects on every edge.
- `createFootprintIndex` (`road-network.js`): **2,884,865** calls (`3,017` consecutive duplicates; `2,474,204` single-cell, `410,661` multi-cell; `2,315,697` `mask = 1`, `569,168` `mask = 2`). On single-cell queries, `1,159,088` hit empty cells and `1,883,318` bucket items were scanned (`199,458` skipped by `flags[id] & mask`).
- `railWithin` (`city-grid.js`): **1,696,124** calls (`33,939` consecutive duplicates; `1,168,970` single-cell, `527,154` multi-cell; `209,896` `mainlineOnly = true`).
- `tram-infra.js` `within` / `nearest`: **1,341,493** / **364,733** calls (`41,495` / `33` consecutive duplicates). `nearest` and `nearestDist` lacked single-cell fast paths and always incremented `stamp` and updated `sg._q`.

## Changes retained

1. **Precomputed `GUIDE_GRID` segment records and bbox / squared-distance rejection in `roadClearance` (`js/city-config.js`).**
   - Precomputes `{ ax, az, dx, dz, L2, half, x0, x1, z0, z1 }` per `LANE_GUIDE` segment, returns `Infinity` immediately on empty cells without allocating `[]`, and skips segments outside `best + half + 1e-9` or `((best + half)^2 * (1 + 1e-12))` before `Math.hypot`.
2. **Packed `Float64Array` vertex coordinates in `createPolygonIndex` / `pointInPolyIndexed` (`js/city-config.js`).**
   - Stores `px` and `pz` `Float64Array`s on each polygon index so `pointInPolyIndexed` reads typed arrays instead of indexing JS `{ x, z }` object arrays.
3. **32 m cells and flag-partitioned `ids` in `createFootprintIndex` (`js/road-network.js`).**
   - Uses `FP_CELL = 32` (halving multi-cell queries and shrinking `cells`) and partitions each bucket's `ids` into `[flag=1, flag=3, flag=2]` slices via `starts[bi + sOff .. bi + eOff]`, removing the per-item `flags[id] & mask` check at query time without duplicating `bounds`.
4. **Single-cell fast paths, hoisted limits and bbox-before-`accept` in `segmentGrid` (`js/tram-infra.js`).**
   - Adds single-cell fast paths (`ix0 === ix1 && iz0 === iz1`) to `nearest` and `nearestDist` (skipping `++stamp` and `sg._q`), hoists `bestD2Lim` and single-cell `lim`, and checks segment bbox before `accept(sg)` in `within` (preserving the exact multi-cell `nearest` bbox-reject lines for `boot-indexes.test.cjs`).

## Rejected attempts (ablated and reverted)

1. **Duplicating `bounds` sequentially per bucket (`bnds`) in `createFootprintIndex` (`js/road-network.js`).** Increased build time (`createFootprintIndex` 84.9 ms) and did not improve query self time (`562.5 ms` vs `537.3 ms` baseline) due to larger memory footprint.
2. **Per-edge `x` range pre-check in `pointInPolyIndexed` (`js/city-config.js`).** Added unpredictable branches in the tight edge loop and stayed neutral (`269.7 ms` vs `271.2 ms` baseline).
3. **Separate `_mainlineCells` map and hoisted `xLo/xHi/zLo/zHi` in `railWithin` (`js/city-grid.js`).** Slightly regressed `railWithin` (`453.7 ms` / `428.0 ms` vs `423.9 ms` baseline).
